# 🦠 COVID-19 Data Analysis Project

## 📌 Project Overview

This project explores the relationship between the spread of COVID-19 and the overall happiness levels of people across different countries. Using data analysis techniques in Python, the goal is to identify whether countries with higher COVID-19 impact show any patterns or correlation with happiness indicators.

This is a data-driven exploratory analysis project combining public health data with social well-being metrics.

## 🎯 Objective

The main objective of this project is to analyze whether there is any meaningful relationship between:

- COVID-19 infection rates across countries
- Happiness levels of citizens in those countries

As a data enthusiast, this project helps in understanding how global crises may impact societal well-being.

## 📊 Datasets Description

1. COVID-19 Dataset
- Source: Johns Hopkins University
- Description: Contains cumulative confirmed COVID-19 cases by country over time
- Key Features: Country/Region, Date, Confirmed Cases

2. World Happiness Report Dataset
- Source: United Nations World Happiness Report
- Description: Contains happiness scores based on various life factors such as GDP, social support, and life expectancy
- Key Features: Country, Happiness Score, Economic Indicators

## 🛠️ Technologies Used

- Python 
- Jupyter Notebook 
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🧹 Data Preparation & Cleaning

- Handling missing values
- Standardizing country names across datasets
- Aggregating COVID-19 cases by country
- Merging datasets for comparative analysis
- Preparing data for visualization

## 📈 Exploratory Data Analysis (EDA)

The analysis includes:

- Global COVID-19 case distribution
- Country-wise comparison of infection rates
- Happiness score distribution across countries
- Correlation analysis between COVID-19 cases and happiness levels
- Visual insights using graphs and charts

## 🔍 Key Insights

- Countries with high COVID-19 cases do not always have lower happiness scores
- Happiness is influenced more strongly by economic and social factors than pandemic case numbers alone
- Regional differences show distinct patterns in both COVID-19 impact and happiness levels
- The relationship between health crises and happiness is complex and not strictly linear

## 📌 Conclusion

This project demonstrates that while COVID-19 significantly impacted global populations, happiness levels are influenced by a broader set of socio-economic factors. The analysis highlights the importance of considering multiple dimensions when studying societal well-being.
